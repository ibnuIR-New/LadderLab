Jobsheet praktikum

Empat jobsheet bertahap. Buka satu bagian per layar, beri satu centang pada K3, alat & bahan, dan teori, centang tiap langkah kerja, tonton video pendamping di bagian Teori, lalu selesaikan kuis untuk melacak progresmu.

Simulator ladder

Simulator berada tepat di bawah jobsheet dan otomatis mengikuti jobsheet yang sedang kamu pilih di atas. Tekan input, lalu amati aliran arus (garis hijau) pada simbol ladder dan keluarannya.

Unggah hasil project

Cara mengumpulkan file .cxt
  1. Selesaikan dan uji programmu di simulator sampai berjalan sesuai spesifikasi.
  2. Simpan dulu project aslinya (.cxp) lewat File → Save.
  3. Klik File → Save As. Pada kolom Save as type, pilih CX-Programmer File (Text Format) (*.cxt). Nama pilihan ini bisa sedikit berbeda antarversi.
  4. Beri nama JobsheetN_NamaSiswa.cxt (contoh: Jobsheet2_Budi.cxt), lalu Save.
  5. Di sini, buka tab jobsheet yang sesuai (review mengikuti jobsheet yang sedang aktif), klik Pilih file, pilih file .cxt, lalu klik Minta review AI.

Menunggu file project.
